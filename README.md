# VM Exchange Analyzer — ядро (этап 1)

Полностью локальный декодер обмена: DOCX-таблица → JSON-конфигурация → декодирование TXT в CSV.
Сеть не используется (в CLI сокеты заблокированы, есть тест).

## Установка на Windows (виртуальное окружение внутри папки проекта)
```bat
cd vm_exchange_analyzer
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Использование
```bat
python -m tools.make_sample samples                          :: синтетические данные
python -m vm_analyzer import-docx samples\sample_arrays.docx -o configs
python -m vm_analyzer decode samples\sample_exchange.txt -c configs -o decoded.csv
python -m unittest discover -s tests -v                      :: тесты
```

## Формат обмена (.txt)
`ВРЕМЯ  НОМЕР_МАССИВА  СЛОВО;СЛОВО;...` — HEX, 16 бит, big-endian по умолчанию
(`--byte-order little` — инверсия). Заголовок «Время…» пропускается.
Номер массива берётся из «Таблица N – Название» (переопределение: `--array-id ТАБЛИЦА#=НОМЕР`).

## Правила примечаний
Записи через `;` или перевод строки, код и описание через дефис/тире; `Остальное – текст`.
Код: `0x..`/`0b..` — явно; только 0/1 и длина = ширине поля — двоичный; иначе десятичный.

## Графический интерфейс
```bat
pip install -r requirements.txt
python -m vm_analyzer.gui --workspace workspace
```
- Панели «Обмены» и «Параметры» можно стыковать, вкладывать друг в друга и выносить в отдельные окна. Внизу — плеер сеанса.
- «Импорт DOCX…» сохраняет конфигурации в `workspace\configs`, раскладки карточек автосохраняются в `workspace\layouts`.
- Карточки: перетаскивание за любое место, размер — правый нижний угол, правый клик — цвета/название/скрыть.
  Значение карточки меняется только когда приходит новая запись её массива и не пропадает между записями.
- Раскладку можно сохранить в файл и загрузить обратно (кнопки в панели «Параметры»).

### Плеер сеанса
Воспроизведение идёт по меткам времени записей: при ×1 секунда сеанса проигрывается за секунду.
Скорости: ×0.1 … ×100. Клик/перетаскивание по линии времени — перемотка; клик по строке таблицы — переход к записи.

| Клавиша | Действие |
|---|---|
| Пробел | воспроизведение / пауза |
| ← / → | предыдущая / следующая запись |
| Home / End | в начало / в конец |
| [ / ] | медленнее / быстрее |
